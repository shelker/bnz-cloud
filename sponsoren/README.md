# Sponsoren-Konfigurator

Vue + Tailwind CSS Konfigurator für Sponsoring-Pakete. Einfach Pakete zusammenstellen, Preise werden automatisch berechnet (inkl. Kombi-Rabatte), Firmendaten erfassen und absenden.

## Starten

```bash
# Entwicklung
npm run dev

# Produktions-Build (Output in dist/)
npm run build

# Vorschau des Builds
npm run preview
```

## Pakete

- **Liederheft**: 1/1, 1/2, 1/3 Seite (70–120 €)
- **Zunftsitzung**: LED Leinwand + TV Vorzelt (250 €)
- **Karnevalszug**: Wurfmaterial ab 250 €
<!-- - **Summerjeck**: Partner, Premium Partner, Presenting Partner (500–2000 €) -->

Kombi-Rabatte: 2 Pakete = 5%, 3 = 10% + vergünstigte Zunftsitzung-Tickets.

## Später

- Backend-Anbindung zum Speichern
- Admin-Übersicht der Anfragen
